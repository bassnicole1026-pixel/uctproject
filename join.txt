Collatz Project — A step-by-step effort to prove that every positive integer eventually reaches 1 under the Collatz map.

Current milestone:
- One-step strict descent for odd n ≡ 1 (mod 4).
- Two-step strict descent for n ≡ 3 (mod 16).
- Three-step strict descent for n ≡ 11, 23, 43, and 55 (mod 64).
- Four-step strict descent for n ≡ 7 or 15 (mod 256).
- Four-step strict descent for n ≡ 143 (mod 256).
- Four-step strict descent for n ≡ 187 (mod 256).
- Five-step strict descent for n ≡ 39 (mod 256).
- Five-step strict descent for n ≡ 79 (mod 256).
- Five-step strict descent for n ≡ 95 (mod 256).
- Five-step strict descent for n ≡ 123 (mod 256).
- Exact computational verification for every starting value from 1 through 100,000.

The descent certificates cover 24 of the 32 odd residue classes modulo 64, with eight finer sub-classes also covered. The full Collatz conjecture has not been proved by this project. Finite computation and partial descent results are not a universal proof.
